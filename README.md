# Portafolio de Analisis de Datos

Repositorio con proyectos academicos y profesionales de ciencia de datos.

## Contenido

### 1. Casos Practicos: Analisis y Optimizacion de Datos en Negocios
Tres casos reales de analisis de datos para optimizacion empresarial:
- **Farmacias Roma**: Optimizacion y prediccion de demanda
- **Refaccionarias del Valle**: Clasificacion y pronostico de componentes
- **Tienda de Telas Modatelas**: Personalizacion de oferta y prediccion de tendencias

### 2. Ciencia de Datos para la Sustentabilidad
Proyecto integrador final: analisis de datos para transformar escuelas en unidades academicas sustentables.

### 3. Certificaciones
Compilacion de todas las certificaciones profesionales (Google, AWS).

## Tecnologias

- Python, R, SQL
- Power BI, Matplotlib, Seaborn
- Scikit-learn, Pandas, NumPy
- Google Cloud / AWS
